新增每张网卡的上行、下行流量监控。

- 网卡卡片显示实时上行和下行速率，每秒刷新。
- 新增“流量监控”页，统一查看所有网卡的速率和本次软件运行期间的累计收发量。
- 不启动分流也能监控，无需管理员权限；仅后台读取 Windows 接口计数。
- 使用实际采样间隔和 64 位计数，处理首次采样、读取失败、计数器重置、断线重连及系统休眠恢复。
- 刷新速率时保留网卡列表和卡片，避免重新创建界面。

统计整张网卡，包括其他应用与局域网流量。虚拟网卡和物理网卡可能记录同一份流量，各网卡不直接求和。累计从首次有效采样开始，退出软件后清零；异常期间不估算缺失流量。本次不增加限速功能。

已有用户可在“软件更新”中检查更新，通过 MUDL 下载并重启安装。保留网卡规则，本次为可选更新。
