NICRoute 现在支持软件内检查和安装更新。

### 软件更新
- 启动后自动检查，也可在“软件更新”页手动检查；两种入口共用一次进行中的检查。
- 提供稳定版和测试版渠道，以及跳过此版本、忽略、下载并重启更新。
- 下载使用 **MUDL-C 0.5.14**，多个镜像共同下载一个文件，最多 **32 个连接**，支持续传和 JSON 进度。
- 由 GitHub 官方更新指针决定版本和摘要；镜像经过完整文件 SHA256 检测后作为备用。
- 下载后及安装前重新计算 SHA256，校验全部安装文件及程序本体的应用标识、平台和版本代码。
- 独立更新程序退出旧版本后替换文件，保留网卡配置；写入失败或新版本不能正常启动时尝试回滚。
- 支持持久化强制更新边界，本次策略为 **0，不强制更新**。

### 安装
下载 `NICRoute-win-x64.zip`，完整解压并运行 `NICRoute.exe`，无需另装 .NET。

**0.1.0 尚无更新模块，需手动安装一次 0.2.0；后续版本即可在软件内更新。**

更新会停止分流并重启程序。已有规则保存在 LocalAppData，不随程序文件替换。备份与更新结果保存在配置目录的 updates 子目录。

更新校验以 GitHub 官方 HTTPS 指针为信任根。当前程序未配置发行方代码签名；若已安装版本具有可信 Authenticode 签名，则要求更新程序签名发布者连续。

继续支持按 Windows 应用/桌面程序分流、全局默认网卡和三种回退。真实系统级 TUN 的性能及多网卡拔插仍需实机验收；本版本没有限速功能。
